# Contributing

This repository is the public Workbench source snapshot. Use `pnpm install` from the repository root, then run `pnpm build`, `pnpm lint`, or `pnpm test` as needed.

The Workbench skill is nested under `skills/workbench`. Keep that path stable so `npx skills add workbench-ai/workbench` continues to work without copying source packages into installed skills.
